## 简短说明

在 Windows 任务栏查看网速、CPU、内存、NVIDIA GPU 和兼容额度状态，并可选择通过第三方服务接收个人提醒。

## 完整说明

TaskbarTelemetry 把常看的本机状态放在系统通知区域左侧，以紧凑的双行布局持续显示，无需打开单独的监控窗口。

你可以一眼查看实时上传/下载速度、CPU 与内存占用、NVIDIA GPU 显存、占用率和温度，以及兼容的 Codex 本地会话缓存中最近一次主额度窗口剩余比例。数值采用固定槽位排版，个位数、两位数和 100 之间切换时不会带动整行跳动。没有兼容 GPU 或额度数据时，相应位置会显示不可用，其余功能照常工作。

可选的个人通知会在额度每跨过一个设定档位时，通过你自己的 Server酱³ 或 Turbo 账户发送（³ 使用独立 App 接收，Turbo 使用微信等已配置通道）。该功能默认关闭；只有你在应用内查看数据用途、明确同意并提供自己的 SendKey 后才会启用。你可以随时立即停用通知并删除密钥。实际提醒数量受 Server酱可用性、每日请求上限和用户套餐约束；应用默认本地每天最多尝试 5 次，可按账户套餐调整，达到上限后当天后续档位只记录、不发送。

隐私设计：本地模式会短暂扫描当前用户近期兼容会话文件的尾部并解析额度事件结构，只保留额度数字和时间；不打开 auth.json，不读取或保存访问令牌，也不提取、持久化或上传用户消息正文。SendKey 由 Windows 当前用户数据保护加密保存，仅通过 HTTPS 提交给 Server酱用于接口鉴权。

Microsoft Store 版不请求管理员权限，不安装驱动、NT 服务或 CPU 温度后端，也不修改 Windows 安全设置。NVIDIA GPU 温度仅在已安装显卡驱动提供兼容接口时显示。

TaskbarTelemetry 是独立第三方工具，与 OpenAI 及 Server酱运营方不存在隶属、合作或背书关系。相关产品和服务名称仅用于说明兼容性。

## 功能亮点

1. 任务栏双行实时状态，默认每秒刷新
2. 网速、CPU、内存与 NVIDIA GPU 指标集中显示
3. 显示兼容的主额度窗口剩余比例
4. 每跨过一个额度档位可选发送个人提醒
5. 第三方通知默认关闭，应用内明确同意并可随时撤销
6. 不打开 auth.json，不保存访问令牌，不上传消息正文
7. 开机启动由 Windows“启动应用”设置统一控制
8. 无管理员提权、无驱动或服务安装
