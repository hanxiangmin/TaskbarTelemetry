# 兼容性与显示约定

## 环境

- Windows 10 / 11 x64、.NET Framework 4.8；水平任务栏。竖向任务栏、多任务栏同时显示不作为本轮验收范围。
- 本地 EXE 使用 `requireAdministrator`，由 Windows 显示管理员确认；不自动批准 UAC。Store 构建维持 `asInvoker`，不带 CPU 温度后端。
- 仅 NVIDIA NVML 硬件计入布局。没有驱动接口或 NVIDIA 设备时使用单卡框架，GPU 显示不可用。
- 有效枚举结果变为零允许回到单卡；临时枚举/句柄失败保留上次真实设备身份，不用旧温度冒充当前值。
- 默认宽度是 528 个 96-DPI 参考像素，随 DPI 缩放；列宽比只取决于单卡/双卡，不取决于当前数值。旧配置没有 `scaleWidthWithDpi` 时保留物理宽度，以免升级后突然变宽；换到更高 DPI 时建议补充 `scaleWidthWithDpi=true`。
- 默认 8.5 pt；CPU 名称为 Consolas，其他文字沿用配置字体。大字号、极窄手动宽度或任务栏可用空间不足时可能裁切；应配套增加 `ui.width`，不会随当前数值自动缩放字体。

## CPU 简写

| 家族 | 前缀 | 示例 |
|---|---|---|
| Intel Core i 系列 | i3 / i5 / i7 / i9 | i7-14700KF、i9-10980XE |
| Intel Core Ultra | U5 / U7 / U9 | U9-285K |
| Intel Core 新命名 | C3 / C5 / C7 | C5-120U |
| AMD Ryzen | R3 / R5 / R7 / R9 | R9-9950X3D |
| AMD Ryzen AI | A5 / A7 / A9 | A9-HX370 |
| Threadripper / PRO | TR | TR-7995WX |

十字位固定为系列 2 + 横杠 1 + 型号 7。未知命名、超长后缀、无法可靠归类的 Xeon / EPYC / Ryzen AI Max 等显示 `CPU`；不截断后缀、不滚动、不补零。完整 WMI 名称在提示中保留。后续新型号先加场景测试再增加规则。

## 额度

Codex 只读取通用额度主窗口，次窗口在提示中列出；不在不同额度池间取最小值，不混入 Spark 专属额度。近期本地快照仍是缓存，不等于实时账户查询。

双来源轮换、暂停、掉线、恢复与过期状态已实现；Kimi 真实数据接入尚未通过关卡。本轮不读私有桌面凭据、不调用未验证的账户接口，不宣称支持全部 Kimi 客户端。官方本地服务的说明与下一步验证条件见 README。

`·` 表示旧值或过期；五分钟后旧百分比不再显示。已连接过的来源在当前进程内保留名称位置；未取得任何有效数据的来源不进入轮换。窗口重置不会被推算成 100%。

## 开源安全边界

源码包使用显式允许清单，不打包本地配置副本、真实 SendKey、同意记录、通知计数、缓存、账户资料、桌面截图或打包身份。README 中的图均为演示数据。构建不覆盖已有 INI；发布包在全新目录中用默认 INI 生成。

当前 GitHub 发布为源码预览，未完成项目在 `VALIDATION.md` 中公开保留。稳定运行包发布前仍须完成桌面回归并由维护者确认。无签名 EXE 可能触发 SmartScreen / Smart App Control；不建议关闭 Windows 安全功能绕过。
