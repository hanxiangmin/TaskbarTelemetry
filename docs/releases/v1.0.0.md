## 一眼看见的功能

- 任务栏内实时查看 CPU / GPU 占用、显存、内存、上传 / 下载与可用温度。
- 自动识别 NVIDIA 单卡 / 双卡：单卡紧凑排列，CPU / GPU 上下对齐；双卡分别展示两张 GPU。
- 单卡显示可用 CPU 核心频率；双卡自动缩写 CPU 型号。
- Codex 通用套餐剩余额度、悬停窗口详情与过期提示。
- 深浅主题、DPI 缩放；可选 Server酱³ / Turbo 手机额度提醒，默认关闭。

## 使用条件与已知限制

- 额度来自使用者自己的 Codex 环境；程序不会提供账户或自动登录。未连接时不影响硬件监控。
- **Kimi 额度尚未接通**；无 NVIDIA 时显示 GPU 不可用。AMD / Intel GPU 监控尚未实现。
- CPU 温度 / 频率取决于硬件、权限及可选官方传感器后端；无传感器显示 `--`。不附带或自动安装内核驱动。
- 本版通过源码编译、依赖来源 / 哈希及 ZIP 内容检查。本机双 NVIDIA 上的单 / 双卡显示获维护者确认；**不代表当前完整自动回归、其他实体单卡机器及所有 Windows / DPI 组合通过**。
- 托盘箭头、截图遮罩、Explorer 重启和鼠标命中诊断仍有待复查事项。诊断探针曾被 Windows 应用控制拦截，未绕过该策略。详见 [验证记录](https://github.com/hanxiangmin/TaskbarTelemetry/blob/v1.0.0/docs/VALIDATION.md)。
- EXE 未做商业代码签名，可能被 Windows 安全策略阻止；不要关闭保护来绕过。

升级时先退出旧实例，新旧版本分开解压；如需保留设置，再复制自己的 INI。此版本是首个公开可下载版本，不是全平台无缺陷承诺。
