## 这次更新

- **网速与测速网页使用相同单位**：`Mb / Gb / Tb` 分别表示 Mbps / Gbps / Tbps，按十进制换算；硬件与网速默认每秒刷新。
- **去掉多余的前导零**：显示 `0.16 Mb`、`12.16 Mb`；数字、箭头和单位使用固定位置，数值变大不推挤其他列。
- **更紧凑的单 / 双卡排版**：自动识别 1 / 2 张 NVIDIA。双卡 520、单卡 476 物理像素；默认不随 DPI 拉宽，中间列两端保留分隔线留白。单卡 CPU / GPU 上下对齐，GHz / GB 的 G 对齐。
- **Codex 额度主动刷新**：默认每 60 秒查询、每 1 秒扫描本地额度事件；改进原生 CLI 定位，减少管理员启动时只能读到旧日志的情况。保留真实更新时间与失败原因，旧数据不会无限续期。
- **更新文档与展示图**：单卡、双卡、深浅主题均与当前绘制代码同步，另增加离线网速与排版检查。

## 从旧版升级

先在旧版小工具上右键“退出”，再解压新包。**建议先使用 v1.0.1 默认配置**：直接复制旧 INI 可能保留旧版宽度和 DPI 设置。需要保留偏好时，备份旧配置后逐项合并。v1.0.0 保留在发布历史中。

## 下载内容与验证

- `windows-x64.zip`：EXE、默认配置、5 个经官方归档哈希校验的运行库、使用说明、隐私 / 许可文件及展示图。不含个人账户、密钥、通知状态、会话或内核驱动。
- `source.zip`：同一提交的源码，可按 MIT License 进行二次开发；再分发须保留许可及第三方声明。
- `SHA256SUMS.txt` 与 `RELEASE-MANIFEST.json`：压缩包校验值、源码提交、依赖来源及包内逐文件哈希。

Windows CI 执行应用 / 测试源码编译、Store 条件编译、独立网速 / 排版检查和文档绘制。此前相同渲染代码已通过 83,883 个离线断言；发布提交的实际结果见 [Actions](https://github.com/hanxiangmin/TaskbarTelemetry/actions)。离线绘制检查不等于全部桌面与硬件回归完成。

## 使用条件与限制

- Windows 10 / 11 x64、.NET Framework 4.8；无需 Visual Studio 或 .NET SDK。
- Codex 使用你自己的登录环境。**Kimi 真实额度尚未接通**，AMD / Intel GPU 监控尚未实现。
- CPU 温度 / 频率依赖硬件、权限和可选官方传感器后端；缺失时显示 `--`，不影响其他指标。
- **EXE 尚未代码签名**，可能被 Windows 安全策略阻止；不要关闭 Defender、Smart App Control 或驱动签名保护来绕过。
- 托盘箭头、截图遮罩、Explorer 重启、鼠标命中及全部 Windows / DPI 组合仍有待回归事项；不宣称全套诊断通过。详见 [验证记录](https://github.com/hanxiangmin/TaskbarTelemetry/blob/v1.0.1/docs/VALIDATION.md)。
