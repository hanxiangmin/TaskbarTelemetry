# TaskbarTelemetry v1.0.2

- 双卡显存单位与温度分别上下对齐。CPU 和 GPU 温度以 °C 显示。
- 任务栏的 GPU 占用率最高显示 99%。悬停可查看实际占用率。
- 内存与 Codex 的百分比共用同一对齐位置，额度过期圆点紧跟数值。
- 网速箭头贴近读数。默认显示 Mb/s，想用 MB/s 时，在 `TaskbarTelemetry.ini` 的 `[network]` 段设置 `rateUnit=bytes` 并重启。

下载 Windows x64 便携包并解压，退出旧实例后运行 `TaskbarTelemetry.exe`。升级时可以保留原有 INI，自行添加网速单位设置。

验证覆盖网速格式、单卡和双卡的离线绘制、不同 DPI 及便携包完整性。实际任务栏和硬件采集仍需在目标机器上验证。
